🌐 Mạng Phân tầng (Dual-AZ)

VPC 10.1.0.0/16 với 2 Public Subnets (10.1.1.0/24 & 10.1.2.0/24) và 2 Isolated DB Subnets (10.1.10.0/24 & 10.1.11.0/24) cô lập 100%.

⚖️ Cân bằng tải & Điều phối

Application Load Balancer port 80 phân luồng: /api/* tới Backend port 8080, /* tới Frontend port 80.

🗄️ Dữ liệu Bền vững & An toàn

RDS MySQL 8.4 db.t4g.micro Single-AZ. Pre-Migration Non-locking Backup qua mysqldump --single-transaction.

🔄 Tự phục hồi (Self-Healing)

Expand-Contract migration, Deep Health Probing (/actuator/health) và Auto-Rollback tức thì về Last Stable Version khi gặp lỗi.
